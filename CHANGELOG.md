# Журнал изменений

Формат основан на Conventional Commits; версии следуют SemVer.

## [0.2.0-alpha.1] — 2026-10-13

### Добавлено

- **assets:** чтение g16 и g17
- **tools:** выгрузка g16 и g17 в oc2-extract
- **assets:** разбор XML-диалекта игры
- **assets:** таблицы текстов интерфейса
- **tools:** oc2-extract check проверяет XML и тексты
- **assets:** изображения JPG, TGA и BMP через stb_image
- **tools:** oc2-extract image и проверка изображений
- **render:** изображения GP по именам из данных игры
- **assets:** поиск текстов по ключам без «#» и перевод UTF-8 в Windows-1251
- **render:** отсечение по прямоугольнику и вывод прямоугольника с текстурой; мышь в окне
- **ui:** шрифты, разметка текста и окна из DialogsSystem.xml
- главное меню при запуске с --data, наведение мыши и ключ --mouse
- **ui:** меню по именам из MainMenu.xml, переходы и модальные панели
- ключ --menu, Esc закрывает текущее меню
- **render:** сплошные прямоугольники fillRect
- **ui:** элементы GP_TextButton, CheckBox, ColoredBar; ComboBox, ListDesk и TabDesk как в оригинале без данных
- чёрный фон под меню

### Изменено

- **formats:** описаны форматы g16 и g17
- главное меню и модуль ui в обзоре

### Исправлено

- **assets:** сборка под Windows — имя far занято макросом windows.h

## [0.1.0-alpha.1] — 2026-10-13

### Добавлено

- **ghidra:** скрипты замера анализа и отчёта о покрытии функций
- **ghidra:** выборочный доанализ функций вне покрытия и с неизвестной очисткой стека
- **render:** окно SDL3 и инициализация Vulkan
- **assets:** чтение спрайтов g2d
- **tools:** утилита oc2-extract для выгрузки спрайтов в PNG
- **render:** вывод спрайтов g2d через Vulkan
- просмотр спрайтов игры (ключи --data и --sprite)

### Изменено

- **ghidra:** многопоточная декомпиляция и вывод прогресса в ExportDecomp
- каркас CMake с пресетами linux и windows-msvc
- **pack:** сборка пакетов deb и rpm через CPack
- **formats:** описан формат спрайтов g2d
- подключена библиотека VMA

### Исправлено

- **build:** сборка под Windows — NOMINMAX для windows.h

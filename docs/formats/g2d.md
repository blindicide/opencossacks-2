# Формат спрайтов `.g2d` (пакет спрайтов GU2D)

Пакет спрайтов: набор кадров, каждый из которых собран из треугольных сеток,
натянутых на текстурные страницы (атласы). В оригинале читается классом
«G2D Sprite Loader» (`FUN_01aaae50` проверяет сигнатуру, `FUN_01aa94b0` разбирает
заголовок, `FUN_01aa9f40` строит кадр, `FUN_01aa97d0` загружает страницу,
`FUN_01b0ce20` декодирует пиксели, `FUN_01a59550` и `FUN_01b08cb0` распаковывают).

В данных GOG-версии 1590 файлов: 1349 версии 6 и 241 версии 5 (эмблемы кланов
в `Internet/Cash/Clans`), 3 файла без страниц. Все числа little-endian.

## Заголовок

| Смещение | Тип | Поле |
|---|---|---|
| 0x00 | char[4] | сигнатура `GU2D` |
| 0x04 | u32 | размер файла |
| 0x08 | u32 | число кадров |
| 0x0C | u32 | смещение таблицы вершин |
| 0x10 | u32 | число вершин |
| 0x14 | u32 | смещение таблицы индексов |
| 0x18 | u32 | число индексов |
| 0x1C | u32 | смещение таблицы частей |
| 0x20 | u32 | число частей |
| 0x24 | u32 | смещение таблицы страниц |
| 0x28 | u32 | смещение области пикселей |
| 0x2C | u32 | число страниц |
| 0x30 | u32 | версия (5 или 6) |
| 0x34 | u16 | ширина спрайта |
| 0x36 | u16 | высота спрайта |
| 0x38 | u8 | назначение неизвестно (встречаются 1 и 9) |
| 0x39 | u8 | флаги, только в версии ≥ 6; бит 0 — у вершин есть цвет |

Размер заголовка — 0x3A байт в версии ≥ 6 и 0x39 в версии 5 (байта флагов нет).
Сразу за заголовком идёт таблица кадров.

## Таблицы

**Кадр** (8 байт): `u32 первая часть`, `u32 число частей`.

**Часть** (18 байт, без выравнивания) — сетка, текстурированная одной страницей:

| Смещение | Тип | Поле |
|---|---|---|
| 0 | u16 | номер страницы |
| 2 | u32 | первая вершина |
| 6 | u32 | число вершин |
| 10 | u32 | первый индекс |
| 14 | u32 | число треугольников (индексов втрое больше) |

**Вершина** (10 байт, или 14 при флаге цвета): `s16 x, y, z` — положение в
координатах спрайта (0…ширина, 0…высота; `z` обычно 0), `s16 u, v` — пиксель
на странице, затем при флаге `u32` цвет ARGB. Без флага цвет равен `0xFF808080`.

**Индексы** — `u16`, номера вершин внутри своей части.

**Страница** (32 байта):

| Смещение | Тип | Поле |
|---|---|---|
| 0 | u16 | ширина |
| 2 | u16 | высота |
| 4 | u16 | формат: младший байт — сжатие (0 — нет), старший — кодировка пикселей |
| 6 | u16 | не используется |
| 8 | u32 | смещение данных от начала области пикселей |
| 12 | u32 | размер данных |
| 16 | u32[4] | назначение неизвестно (часто `0x7FFFFFFF`) |

## Кодировки пикселей

Результат всегда — ARGB4444 (16 бит на пиксель, альфа в старших битах).

- **0** — готовые ARGB4444, `ширина × высота × 2` байт.
- **1** — палитра и отдельная альфа. Байт `n`, затем `n + 1` цветов по 3 байта
  (R, G, B; используются старшие 4 бита каждого), затем по байту индекса на
  пиксель, затем по 4 бита альфы на пиксель (старшая тетрада — чётный пиксель).
- **2** — палитра (как в кодировке 1) и поток байтов. В байте биты 0–2 — альфа
  `a`, биты 3–7 — индекс `i` (до 32 цветов). Если `a = 0` и `i ≠ 0`, пиксель не
  выводится, а следующие `i` пикселей получают младший бит альфы. Иначе выводится
  пиксель с альфой `a·2 (+1)`. Распаковка идёт, пока не набрано `ширина × высота`.

## Сжатие

Сжатая страница начинается с 9 байт: `u8 метод`, `u32 сжатый размер`,
`u32 исходный размер`. Метод 1 — bzip2, 2 и 3 — LZO1X, 4 — FLZ. В файлах .g2d
GOG-версии встречается только метод 4.

### FLZ

Битовый LZ-формат. Первый байт — флаги, затем (при бите 0 флагов) `u32` —
смещение таблицы литералов от позиции этого поля; первый байт таблицы — её
длина минус один, значения — со следующего байта. Дальше — поток битов: 32-битные
слова в порядке big-endian, биты читаются от старшего, то есть это просто
байты подряд от старшего бита.

`var(w)`: прочитать `w` бит в `n`; если `n = 0`, результат 0, иначе
`(1 << (n − 1)) | следующие n − 1 бит`.

Состояние: ширина вида `wk = 4`; ширина длины `wl` = 3 при бите 2 флагов, иначе 2;
ширина литерала `lb = 8`, основа литерала `lbase = 0`, старшая часть дистанции `hi = 0`.
Таблица режимов: `T[0]` = `0x403` при бите 2 флагов, иначе `0x402`; `T[1]` =
`0x503` при бите 1, иначе `0x403`; `T[2] = 0x504` (старший байт — `wk`, младший — `wl`).

Цикл, пока не выведено нужное число байт:

1. Бит 0 — литерал: `v = bits(lb) + lbase`, при наличии таблицы `v = таблица[v]`; вывести байт.
2. Бит 1 — `k = var(wk)`:
   - `k = 2…4`: `wk, wl` берутся из `T[k − 2]`;
   - `k = 1`: `v = var(4)`, `lbase = v / 9`, `lb = v % 9`;
   - `k = 5`: `len = var(wl)`; повторить последний выведенный байт `len + 1` раз;
   - `k = 0` или `k ≥ 6`: `len = var(wl)`; дистанция `d = var(3) + hi · 128` при
     `k = 0`, иначе `d = k`; `hi = d >> 7`; `n = len + 3`; скопировать `n` байт,
     начиная с позиции `выход − (d − 6 + n)`.

Копирование в оригинале идёт 32-битными словами, поэтому при перекрытии
(`d < 6`) результат отличается от побайтового: нужно повторять пословное копирование.

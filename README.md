# opencossacks-2

Открытая реимплементация движка *Казаки II: Битва за Европу* (GSC, 2006),
созданная на основе изучения оригинального `engine.exe`. Для запуска нужны данные
игры из легально приобретённой копии (например, GOG); оригинальный код и ресурсы
в репозитории не хранятся.

## Структура

- `src/` — исходники реимплементации
- `docs/` — заметки о форматах файлов и поведении движка
- `tools/ghidra_scripts/` — скрипты для headless-анализа в Ghidra
- `re/` — локальная папка (в .gitignore): проект Ghidra и вывод декомпилятора

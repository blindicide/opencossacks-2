# opencossacks-2

> **Статус: заброшенный (legacy) проект, репозиторий в архиве.**
> Реимплементация не доведена до рабочего состояния: отрисовка карты некорректна
> (рельеф с муаром и артефактами, чёрная полоса у края), баланс и многие числа
> подобраны на глаз, игра не проверялась в полноценных матчах. Проект больше не
> развивается и не поддерживается. Код, заметки о форматах (`docs/`) и скрипты
> анализа остаются открытыми под GPL-3.0 — их можно использовать как справочный материал.
> Последний релиз: v0.9.0-alpha.1.

Открытая реимплементация движка *Казаки II: Битва за Европу* (GSC, 2006),
созданная на основе изучения оригинального `engine.exe`. Для запуска нужны данные
игры из легально приобретённой копии (например, GOG); оригинальный код и ресурсы
в репозитории не хранятся.

## Запуск

Пока движок умеет показывать спрайты игры:

```sh
opencossacks2 --data <папка игры>/app --sprite UnitsG17/FrnPopU.g2d
```

Клавиши: ←/→ — кадр, ↑/↓ — на 10 кадров, пробел — анимация, +/− — масштаб, Esc — выход.
Все ключи: `opencossacks2 --help`.

## Структура

- `src/` — исходники реимплементации
- `docs/` — заметки о форматах файлов и поведении движка
- `tools/ghidra_scripts/` — скрипты для headless-анализа в Ghidra
- `re/` — локальная папка (в .gitignore): проект Ghidra и вывод декомпилятора
